# Vendor-hour interpretation and source clock

The [pinned publisher card](https://huggingface.co/datasets/twelvedata/financial-world-model/blob/ad48edaf3828ec855ab4a5bb1b8336fa0b68cdec/README.md) calls timestamps interval starts in America/New_York. Prior full-history metadata/census found top-of-hour and 09:00 regimes; that evidence is inherited from the hash-bound acquisition audit, not newly reread protected prices. The active post-June-2022 grid admits only source keys exactly at XNYS session-open plus integer hours whose nominal end is entirely inside RTH. No relabeling of top-of-hour bars and no splitting unknown hourly bars.

Ordinary days supply 09:30, 10:30, 11:30, 12:30, 13:30, 14:30 starts, ending 10:30–15:30. 15:30 terminal rows are excluded. Early-close days contribute three genuine scheduled full hours, with no four-hour target origin and no regular daily proxy. Late/terminal/off-grid observations are never admitted merely because timeframe says 1h. Raw 07:30 and anomalous early-close keys are source QA only. America/New_York changes UTC offset with XNYS DST; for example first start is 14:30Z on 2024-03-08 and 13:30Z on 2024-03-11.

Bounded cached JNJ 30-minute constituents match the same nominal full-hour starts/ends and nearly identical prices. They do not independently certify the HF builder or share-volume basis. Corrected source_evidence_v2 excludes all stubs from these comparisons. Exact transaction aggregation, historical release time and build-to-source attestation are unverified. The researcher therefore approved **IDEALIZED_VENDOR_HOURLY_AS_REPORTED**, not observed-live or executable-price certification.

Record start/end, assumed information boundary, UNKNOWN source available_at, nominal issuance, proxy references and label maturity separately. Forecast issuance is end+2 minutes; source information is idealized at end. Entry/exit references are completed closes separated by exactly four same-session scheduled hours; label maturity is exit end+2 minutes. No three-minute fill or portfolio execution is claimed.

Arrow applies the date predicate before Python OHLCV materialization. Internally decoded compressed pages can contain discarded protected dates; no protected numeric rows enter an application frame, store, diagnostic, feature or label. Key-only scans project no OHLCV. The new barrier is 2026-01-07; the legacy source comparison barrier remains 2024-07-01 independently.
