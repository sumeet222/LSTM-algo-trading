# GARCH11-STRICT999 implementation and frozen interpretation

This document explains the protocol already fixed in readiness.json and prefit_gate.json; it introduces no new fitting choice. The only change from the attempted predecessor is the uniform persistence cap.

`Strict999GARCH` inherits the installed arch 8.0.0 public GARCH class. It overrides only `constraints()`, verifies the package's final row is `[0,-1,-1]` with bound -1, and changes that bound to -.999. The inequality is `A @ parameters - b >= 0`. `ConstantMean(..., volatility=Strict999GARCH(p=1,o=0,q=1), distribution=Normal(), rescale=False)` retains the supported Gaussian likelihood, optimizer, deterministic package starting-value recipe, backcast, parameter bounds and bounded numerical variance recursion. Package source/API inspection is saved. No monkey-patching, hand-written likelihood optimizer, penalty, or post-estimation projection is used.

All 560 input vectors were independently authenticated before fitting. The original stock-slot greedy history permits start == previous retained end; 59 rejected origin histories do not remove any evaluation row. Each unit uses the same archived restricted prefix ending in September, including its original 48-full-hour embargo. Oct–Dec and the following outer year are excluded from parameter fitting. x=100R; means divide by100, variances by10000. One package fit per unit: SLSQP, maxiter1000, tol1e-9, ftol1e-9, unchanged default starts. No failed unit can be restarted by this task.

The final unrounded optimizer vector is saved and compared exactly to the reported coefficients. Omega must be strictly positive, alpha and beta nonnegative, and persistence less than1. Cap slack=.999-(alpha+beta) must be >=-1e-10; abs(slack)<=1e-8 denotes cap contact. A negative slack inside1e-10 is explicitly classified as a roundoff overshoot, not rounded away. Finite positive conditional and unconditional variances and convergence flag0 are required. Package bounds and bounded conditional recursion are independently audited. Successful termination and theoretical admissibility are separate gates.

Given the final prefix conditional variance h_n, the next state is omega+alpha*(x_n-mu)^2+beta*h_n. Later signed endpoint-return events update that state only when endpoint+2 minutes is strictly before forecast issue. No coefficients are refitted. The next-observation interpretation of this irregular same-slot process is retained; it is not continuous-time integrated 240-minute variance. The folded-normal expectation uses mu/100 and h/10000, including the absolute-mean zero-variance limit. Conditional normality is a modeling assumption.

Only after all560 units pass may new G and IO coefficients be fitted from their own preceding Oct–Dec independent calibration rows. Shared `hf20_matched_math.fit_common` and `apply_common` are reused unchanged. IO uses category-normalized session mass, n_eff=1/sum(p_session^2), shrinkage n_eff/(n_eff+25). None of the nine old raw predictors,18 old G/IO arms, native calibrated packages, or neural outputs are refitted. Their saved columns are copied exactly and byte-preserved at source. Report-only replay reads scores and does no fitting.

The estimand remains genuine240-scheduled-XNYS-minute endpoint absolute log return. The nominal target origin precedes the historical approximate origin+2-minute publication proxy. Actual vendor arrival was not measured, and these labels are not post-issuance executable P&L. Frozen20-stock order, early closes, overnight crossings and source revision776328445b7ac6e7815ef3a483e9c8ded1eb6d56 are unchanged. No raw minute source,2025 market values or protected2026 material is accessed.
