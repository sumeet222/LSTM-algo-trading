A7 — Market-conditioned input gates (MC1 / conditional MC2)
Let approved stock features be x_{i,s} ∈ R^16, market state m_s ∈ R^d_m, historical steps s=t-47,…,t. A same-information plain control would consume [x_{i,s};m_s]. A conceptual endpoint-gated A7 consumes
MC1: [ alpha(m_t) ⊙ x_(i,s) ; m_s ]
while the stepwise alternative consumes
MC2: [ alpha(m_s) ⊙ x_(i,s) ; m_s ].
For a MASTER-style gate, one possible family is alpha(m)=16*softmax((Wm+b)/tau), zero logits yielding all-ones identity. This is a candidate family requiring a freeze-card decision; it is not automatically the current HF20 choice. The direct market-state channels must remain present in both gated and ungated information-matched models, avoiding a gate-versus-information-availability confound.
- One A7 fit only. Default research preference is MC1 if a compatible source exists. MC2 must be explicitly selected instead of MC1 after a training-prefix causal within-window state-transition/step-variation audit; never secretly fit both under one A7 start. The unused variant stays recorded as not fitted. An additional comparison later is a new approval/start.
- Test identity at initialization, dynamic gate variation by time/state/feature, entropy/saturation/collapse, gradient connectivity, state age/mask semantics, difference between latest-state reinterpretation and per-step conditioning, and a planted toy case in which indicator relevance changes with a contemporaneously observable state.
- If gate improves relative to T2 alone but there is no trained same-state, ungated LSTM, report possible information-plus-architecture benefit only, not proof of the gate mechanism. Preserve need for an approved same-information neural control in a future claim.
A8 — Shared global–local recurrent memory (C3/S3)
This is a distinct hypothesis about recurrently estimated common state, not a repeat of A5/A6 final-state stock mixing. At each historical step, conceptually:
p_s          = mask_aware_pool(phi(x_(1,s)), ..., phi(x_(20,s)))
g_s, cG_s    = GlobalLSTM([m_s; p_s; optional_previous_mean_local_state],
                          g_(s-1), cG_(s-1))
h_(i,s),ci_s = SharedLocalLSTM([x_(i,s);g_s], h_(i,s-1), ci_(i,s-1))
yhat_(i,t)   = shared_head(h_(i,t)).
This is the illustrative C3 construction in Recurrent_Architecture_Research.md, not a preapproved shape or a requirement to include optional feedback. Select exactly one parsimonious global/local pathway in the preflight card. The common state is updated once per historical time step; it must not be updated once per stock in arbitrary ticker order. Maintain stock-mask handling, 48-step independent window resets, causal global-before-local update timing, deterministic batching equivalence, and strict absence of future peer measurements.
- Test an identity/null global-to-local coupling and nontrivial state-conditioned changes to relative scores, not merely a common additive score shift.
- Synthetic mechanisms: planted shared latent state with stock-specific responses; null/no-common-state case; optional peer-specific counterexample showing that global averages discard individual innovations. Check gradients through the global path and local path, state dynamics, hidden variability and sensitivity to removing/perturbing the global stream.
- If A8 sees pooled peer histories not supplied to the existing ordinary T2, this is additional information as well as a new memory architecture. Explicitly inventory that access and do not attribute its entire gain/loss to global–local recurrence. A rich-input plain LSTM matched to all actual global/pool inputs is a separate comparator requiring approval if not already saved.
A12 — State-conditioned expert readout heads (not feedback adaptation)
Test the minimal version of regime-specific prediction maps on a single shared ordinary recurrent encoder, without a new set of fully independent recurrent experts, VQ codebook, automatic hard clustering, hindsight bull/bear labels, or online uses of unobservable completed outcomes.
h_(i,t)   = SharedLSTM(stock and approved state history)
pi_t      = soft_state_weights(approved_causal_market_state_at_t)
yhat_(i,t)= Σ_(k=1..K) pi_(t,k) * head_k(h_(i,t)).
K, the temperature/regularization, expert-head form, whether gate state is continuous, and a principled K=1/constant-head null must be explicitly frozen in §1, not inferred from paper defaults. Favor the smallest data-supported K; assess actual independent regime episodes, not merely the raw count of stock-hours.
