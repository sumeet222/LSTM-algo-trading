A1 — TM1_ATTENTION (exact compact identity-preserving attention)
Given all h_s∈R^32 output by the unmodified LSTM for a stock, define
u_s      = qᵀ LayerNorm_no_affine(h_s) / sqrt(32)
a_s      = softmax_over_48_steps(u_s)
c        = Σ_{s=1}^{48} a_s h_s
h_att    = h_48 + gamma * (c - h_48)
z_hat    = original_T2_scalar_head(dropout_0.10(h_att))
Use one shared 32-vector q and one scalar trainable gamma, initialized gamma=0 so exact TM0 readout identity holds at construction; small, documented seeded q init; no positional embeddings or new attention dropout. q: weight decay 0.01; gamma: 0; normal head and base LSTM retain original groups. Expected trainable parameters 6,466; verify by enumerating parameters, not relying on expected counts. For all-zero gamma, derivatives into q start at zero by construction; verify gamma's gradient at step 0 and q's gradient when gamma≠0 on synthetic or held-input no-update backward pass, and log actual gamma trajectory/attention distribution once trained. No future steps, market peer inputs or attention as causal explanation.
A2 — TM3_MULTISCALE (single, bounded StockMixer-inspired causal temporal mixer)
This is not TM4 (multiple large separately fitted encoders). Freeze one economical, deterministic implementation before training:
For every stock and each input time index s=0..47, from its already-frozen 16-channel scaled FT16 input compute the trailing means:
A1[s,:]  = X[s,:]
A4[s,:]  = mean_{u=max(0,s-3)..s}  X[u,:]
A12[s,:] = mean_{u=max(0,s-11)..s} X[u,:]
M[s,:]   = Linear( concat[A1[s,:],A4[s,:],A12[s,:]], out=16 )
h_48     = unchanged_single_layer_LSTM_16_to_32(M)[final]
z_hat    = unchanged_scalar_T2_head(dropout_0.10(h_48))
- Temporal windows [1,4,12] are counted in scheduled already available feature steps, not clock minutes or arbitrarily extending beyond the same 48 input positions. Prefix denominator uses actual in-window available steps (s+1 until full window), no padding with future/next-day values and no extra raw candles or additional network input fields. Preserved original quality masks and train-fit fallback provenance carry through: partial input values already vetted by P020 are the only source. If the existing loader's missing-channel semantics make such averaging scientifically ambiguous, demonstrate that before approval and propose an explicit mask-aware equivalent—do not silently modify data/masks.
- Linear(48→16) is the only additional trainable mixing module (weight 16×48, bias16), initialized with [I_16,0,0] and bias zero: at initialization the complete A2 prediction is an exact numerical identity to the same-initialized TM0/T2 LSTM. However, all 3 blocks can learn weights; the first path remains present. No nonlinear activation, exogenous data, feature-channel count change, temporal attention or skip-to-output head. Include Linear weight in original matrix decay 0.01 and bias in no decay. Expected parameter count 7,217; verify. This is a controlled, modest learned multiscale representation built from existing input, not a separate feature-search or data modification.
- Show that the generated states are causal by a suffix-perturbation test (change future sequence steps, earlier representations unchanged), time indexing, exact [B,20,48,16] shape, identity initialization, window1/4/12 branch gradient flow, coefficient norms and learned scale contributions. Frozen engineered indicators already cover several horizons; any claimed gain must exceed T2, not merely demonstrate nonzero mixer weights.
