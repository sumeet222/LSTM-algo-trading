4.2 S9-A MAG: magnitude of raw endpoint return
Define price-only four-trading-hour endpoint log return R_{i,t}^{(4)}=log(P_exit/P_entry) using the actual S4 source-price convention. Model the nonnegative magnitude A_{i,t}=|R_{i,t}^{(4)}| (not |TG20|, not realized intrapath volatility). Choose one train-prefix-only deterministic scale s>0 based on allowed historical magnitudes and freeze a numerically stable monotone transform, preferably m=log1p(A/s). Predict m with a small linear output and MSE/Huber only if the selection is fixed before OOS; the intended default is ordinary MSE of log1p(A/s), no hyperparameter sweep. For reporting, invert once via Ahat=s*expm1(mhat) with a nonnegative inference constraint clearly stated; don't alter the optimized target invisibly. Explicitly distinguish transformed loss, original-magnitude MAE/RMSE, and calibration.

Essential same-target controls: training-prefix-only constant absolute-move level (global and/or stock-specific, correctly fitted), a simple trailing absolute-return/EWMA volatility proxy scaled to the four-hour horizon without hindsight, and a simple nonrecurrent same-FT16 lagged regularized magnitude regression only if the existing ridge fit utility can be reused cheaply. No new intensive hyperparameter search. Report incremental loss/MAE versus each on matched observations and quantify whether predicted larger moves actually correspond to larger subsequent absolute moves.
4.3 S9-B EVENT: tail-event risk, not direction

Otherwise define one predeclared train-prefix-only positive cutoff c on a documented |TG20| or |raw R| scale (but do not interchange them). Label E_{i,t}=1{|target|>c}. One scalar logit per stock with stable binary cross-entropy; no class weighting by default because weighted probabilities are not automatically calibrated. Freeze the event metric and cutoff before OOS. If original E1 was multiclass (positive/negative/ordinary), retain the original label semantics where practical and report ANY-tail probability as a lawful sum; do not falsely claim equivalence to a differently defined binary model.

Essential controls: train-prefix-only event rate (global, stock and/or predeclared clock group as sample size supports), and the simplest trailing-absolute-return or volatility-driven event proxy if already available. Judge by Brier score, log loss, event average precision / PR curve, ROC AUC as secondary, calibration/reliability, precision/recall at training-frozen thresholds and event prevalence. A gain in AP with worse log loss is a discrimination/calibration tradeoff, not an across-the-board event probability win. Report both positive and negative TG20 tail components only if labels permit; never turn ANY-tail into long/short direction.
