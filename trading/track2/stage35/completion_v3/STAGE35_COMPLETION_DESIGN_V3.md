# Stage35 V3 engineering boundary

This is an additive successor. Stage012, Stage35 V1/V2, original C-A/O1/CLOCK/C3,
Phase2/3, original sources and previous evidence remain immutable. No model fit,
new forecast panel, historical strategy orders, investment cash, NAV, returns or
performance evaluation ran. The 131,111 original forecasts remain reusable.

The layers are: cached free-action responses → evidence-preserving reconciliation
→ observed canonical events plus separate assumptions → raw-share observation and
due-event tapes → existing V2 physical/virtual book through the V3 action bridge.
The same immutable raw-open execution, netting, participation, reservations,
fixed endpoints and disabled dynamic policy remain in force. No action field
enters the frozen original signal producer or its opportunity universe.

`actions.py` validates types, issuer roles, units and truth. `inventory.py` performs
observed reconciliation before any inference; conditional records cannot be
upgraded by that reconciler. Acquirer merger notices do not entitle its existing
common holders to the acquiree's merger consideration. Multiple COP base/VROC
cash components remain separate; variable returns are not extrapolated as fixed
regular payouts. Source errors, absent fields and empty feeds are different states.

`tapes.py` compiles dated actions and payments, including January 2025 payments
for December 2024 ex-dates, without any 2025 price access. Carry is emitted for
active physical net shorts only, segmented before rate/mark/share changes and at
calendar midnights. `engine.py` wraps the unchanged V2 replay/expiry/receipt engine;
`book_bridge.py` posts ex/payment journals without inventing a midnight quote.
An old mark converted by a verified split remains old and stale, with the factor
explicit in its source identity. An actual later raw observation replaces it.
Short proceeds remain an access-restricted subset of cash, counted once.

Claims belong to shares immediately before the ex event. Payment transfers a
claim into attributed cash once, even if that cohort has since exited. An unknown
pay date retains an undated claim; funding failure retains the debt and holds
risk. Splits change physical/virtual/pending units together and never fabricate
CIL. Unpriced special assets remain visible and block release. The MRK case has
explicit OGN quantity receipts but no invented valuation. Voluntary JNJ exchange
uses a reviewable no-election convention, not an automatic Kenvue distribution.

Historical financial entry verifies the independent signed V3 release before
calling a loader or creating any output. Trusted reviewer anchors are empty.
The existing V2 raw-price guard also prevents booking this session's actual
prices into its synthetic book. Therefore the allowed historical witness uses
an isolated `ClaimShareBook` with synthetic endowed quantities, actual action
facts and actual raw-observation validation. It has no trade, cost-basis, NAV or
P&L API. Funded accounting/replay tests use fabricated prices only. This explicit
separation is the user-authorized fallback to isolated consistency witnesses.

`restart.py` serializes a closed allowlist to JSON, never pickle/eval. A checkpoint
binds input identities, payload hash, account/arm, full book/journal, pending
orders, carry cursors, receipt times and action provenance. Resume verifies its
append-only receipt hash, exact input binding, journal chain and book invariants.
Historical resume needs a fresh exact financial release. Legacy Cohort metadata
must satisfy its existing float schema; Decimal money/shares in economic lots
remain Decimal. Unsupported metadata fails instead of silently converting it.

This is an application-level research release control, not an OS sandbox against
arbitrary edits to Python. Independent trust-anchor registration, code review and
signed exact hashes are required in a separately authorized successor. Neither
editing a JSON flag nor supplying an agent-created key clears this release.
