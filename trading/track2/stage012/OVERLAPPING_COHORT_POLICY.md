# Fixed cohorts, net shares and accounting boundary

Cohort identity convention: (model_version, origin_utc, ticker, strategy_arm), serialized stable string. Caller uniqueness is enforced when reserving. Each immutable replacement appends an event; duplicate IDs and backwards times fail. New origins leave held cohorts unchanged. Dynamic policy and REBALANCE event both fail closed.

Entry order -> partial/open fills -> endpoint exit order -> partial/closed fills are synthetic deterministic transitions. Late entry fills reject; caller cancels by deadline. Missing exit/halt/buy-in/action/borrow/financing events become UNRESOLVED. Splits/dividends are typed boundaries, not complete economic accounting. Entry average price is recorded; exit_price is last synthetic fill, not weighted whole-lot exit basis. No realized P&L computed.

Net physical shares=sum virtual signed shares: old+10 and new−6 imply+4; old exit−10 leaves−6. Net-order quantity is sum signed deltas. Same-side external fills and fees allocate pro rata with residual to final ID in supplied stable order. Mixed opposing entry deltas reject INTERNAL_CROSS_ALLOCATION_UNSUPPORTED: a later approved internal transfer price/fee convention is required, so this package cannot manufacture profits by fictional independent physical long and short holdings. Example geometry is tested without executing an unsupported mixed allocation.

Reservations conserve gross virtual notional and own cash/collateral. Short sale proceeds never replenish capacity; real borrow availability is unknown and fails closed. Reservations persist through partial fills and unresolved states, release only flat CLOSED/REJECTED. No sale-proceeds ledger, dividends owed, borrow rate, financing or broker margin calculation exists. No production risk mark-to-market exists. Full-vintage20% allocation across names, dynamic NAV checks, automatic deadlines and missing-observation recovery are future integration work. Interfaces remain unsuitable for historical execution until Stage3 closes these items.
