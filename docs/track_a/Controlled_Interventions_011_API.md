Use the existing repository environment and canonical Package004 stock store. No new dependency or data download is required. This is candidate retrospective development only; production D1 and confirmation remain protected.

The batch observer records canonical squared loss even when optimizer loss differs; epoch logs name both objectives.

`ControlledAuthority` is an exact sealed type admitted at the existing `require_training` boundary. It binds one of 18 fixed identities to actual live approval, code, data views, separate target parameters, deadline, prior six pairs and linked registry v4. `ensure` checks the current source and code. Only Finder `.DS_Store` is excluded from the raw guard; every other source path retains byte/stamp checks. Old v1–v3 journals and production pointer are immutable. Every STARTED consumes one slot, including failures. No retries/reordering/overlapping pairs.

`real_bridge_run.epoch_pass` remains the single real numerical loop. Default callers retain old seed42/MSE/clip1 behavior; only exact controlled authority invokes the isolated adapter. Sampler and initial/refit models use the bound seed. T2 is inverted once before canonical metrics; original-scale inner MSE drives unchanged D6g. Both calibration/refit warnings remain visible. O1 logs both historical >1 exceedance and actual cap5 scaling.
