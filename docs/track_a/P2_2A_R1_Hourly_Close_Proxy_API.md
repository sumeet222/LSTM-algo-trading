# P2.2A-R1 hourly-close proxy API

Synthetic implementation authorized after human acceptance of the original P2.2A foundation. Scientific source and execution approvals remain separate; outputs always research_ready=False and execution_outcome=NOT_EVALUATED. No provider request, fill engine, portfolio policy, risk/retry, M2 calculation, production label dataset or protocol-pointer migration.

Implementation: `src/lstm_data/hourly_proxy.py`. Original `src/lstm_data/labels.py` and `tests/test_labels.py` remain byte-identical. New tests: `tests/test_hourly_proxy.py`. Follow README setup and run `python -m pytest tests/test_hourly_proxy.py tests/test_labels.py -q` (53 tests).

| Entry point | Contract |
|---|---|
| HourlyCloseReference | Immutable exact one-hour raw stock CLOSE with symbol/row ID/source version/start/end/availability basis/evidence. Reject adjusted/total-return prices, stub, index source, nonfinite/nonpositive price and availability before completion. No aggregation or adjustment guessed. |
| resolve_reference(rows,plan,symbol,event,*,side=None,test_scenario=False) | Exact P2.1 calendar slot, ENTRY=cutoff and EXIT=cutoff+4 clock hours. Returns ExecutionReference: source row/price, side, expected completion, actual scheduled event, lag_seconds, valid_at_event and reason. Missing/unknown clock fails closed; no fallback to minute or nearby row. Price remains diagnostic when valid_at_event=False. |
| proxy_causal_eligibility(plan,forecast,entries,*,test_scenario=False) | Accepted upstream ForecastEvidence/full FT0 assertion and per-name entry reference checks; no exits/actions/floors. This module does not compute complete FT0 inputs. Same close is input endpoint: require availability by original cutoff, not delayed issuance. P3 admission/fillability not evaluated. |
| proxy_label_sample(plan,forecast,entries,exits,*,observed_at,actions=None,test_scenario=False) | Five price-reference log returns, median/unscaled MAD, refs/versions/source/action IDs, actual maturity=max(scheduled exit, required supported availabilities), separate causal flags. Missing future exit invalidates label without changing prior entry. A later mature label never certifies an earlier fill. |
| proxy_fitting_membership(sample,window,*,test_scenario=False) | Accepted frozen fitting membership/purge rules with proxy-version checks; rejects minute samples. Shared fitting_window unchanged. |
| fit_proxy_floor(samples,window,*,test_scenario=False) | Reuses accepted training-only max(1e-4,0.1×training median MAD); rejects validation fit/mixed minute artifacts/duplicate origins/empty population. Binds reference prices, intervals, clocks, lags and execution/target/M2 versions to floor identity. |
| apply_proxy_floor(sample,floor,*,test_scenario=False) | Requires ProxyFloor and consistent proxy lineage; reuses accepted TG0 standardization with no clipping/refit. Returns version-tagged ProxyTG0Target. Cannot wrap a minute floor under proxy name. |

Versions: `COMPLETED_HOURLY_CLOSE_PROXY:v1`, `TG0:HOURLY_CLOSE_PROXY:v1`, `M2:HOURLY_CLOSE_PROXY:v1:REBUILD_REQUIRED`. No change to existing minute defaults; use these R1 wrappers for proxy fitting/application. Original minute entry points remain the original contract; callers must not bypass version guards by calling them on proxy subclasses. Historical M2/floors/scalers/labels need recomputation under proxy lineage; M2 itself is not implemented in R1.

Ordinary nominal source intervals:09:30–10:30→13:30–14:30 and10:30–11:30→14:30–15:30 ET. Scheduled events10:33→14:33 and11:33→15:33;180-second nominal proxy ages. Delayed issue10:35 gives10:36→14:36 events but source endpoints10:30/14:30;360-second ages. Original cutoff never shifts. Early closes/invalid plans rejected by unchanged P2.1. No seventh full-hour closing stub or arbitrary shift(4).

Raw-price share conversion uses accepted SplitFact validation, but the price-return factor interval is explicitly(entry CLOSE,exit CLOSE]. Require ActionScope covering cutoff through scheduled exit; this prevents silently missing a split between cutoff and scheduled entry. A split after exit reference completion does not alter that reference-boundary price return; P3 scheduled fill/share treatment remains separate. Dividend cash is not added to TG0. Source/rate/share/aggregation semantics remain externally evidenced facts; ASSUMED availability inactive, synthetic requires opt-in.

Hourly proxy assumes older observed close as a later execution price, with possible delay bias. Cost bps do not certify coverage. The source store's split-adjusted prices cannot be passed as raw references without proven conversion. No minute retry/continuous risk/benchmark boundary claims. Shared execution proxy approval, source publication/coverage/actions, full eligible fitting population and hourly portfolio exception-policy decisions remain unresolved under the registered amendment; no global G0/G1/G2/G4 PASS or scientific freeze updated.
