1. From the repository root run `./scripts/run_track_a_dashboard.sh` and open its printed localhost URL. Use the existing repository `.venv` setup and `.[visualization]` extra; no reinstall is needed when already provisioned. On **Start Here**, click **Package 011: Compare C0 and T2**. The original **Price & Features** AAPL/WF2/January16–19,2024 demonstration remains available.
2. On **Controlled Experiments**, keep **Study → Package 011**, **Treatment → T2**, **Paired comparator → C0**, **Study fold → WF1**, **Study seed →42**, **Study stock → All stocks** and **Study origins → Both**. Under **Study view → Target & denominator**, choose **Registered training population → Full refit prefix**, then compare with **Inner-training prefix**. The three panels contain original canonical TG0, T1 clipped optimizer labels and T2 asinh optimizer labels, each with its own horizontal units. The actual immutable cap, s, prefix, preparation ID and parameter IDs appear above. These training populations are independent of the sidebar development dates and seed. Stock/origin filters subset the displayed observations without refitting parameters. Toggle log counts or central p1–p99 zoom; full quantiles still use every selected observation. The raw/asinh scatter and inverse round-trip error describe labels, not saved forecasts. Display transforms use the registered float64 label population; optimizer arithmetic was float32.
3. Choose **Study view → Training Curves & Gradients**. **Study pass → calibration** compares the actual optimizer objectives in separate, named panels, then original-TG0 inner-validation MSE in a common panel. Selected epochs, recorded stops and warning onset are marked. Switch to **refit** for the fresh trajectory. Historical WF1 C0 batch history and unrecorded applied fractions say **Not recorded** or remain gaps. Batch loss/norm scatter is an association, not causal evidence.
4. Restore **Treatment → T2**, **Study partition → Development** and choose **Study view → Predictions & Errors**. Dates initially select July17–20,2023 on WF1. Metrics always use all five stocks, equal stocks → origins → sessions; the Stock control affects plotted traces only. The fold×seed table and its documented five-session exploratory intervals ignore the local filters and do not establish selection-adjusted significance.
5. Choose **Study view → Extreme Events**, then check the full recorded partition option. With WF1/seed42/T2 and **Extreme event ordering → Highest |TG0|**, the first saved event is **SBUX, November17,2023,11:30 ET (16:30 UTC)** in **TA011-T2-S42-WF1**. The button sets the exact fold/model/partition/stock/date/origin, opens genuine candles with matching volume below, and enables horizon markers. Open **Feature Scaling Explorer / actual 48-step context**, check **Open read-only Feature Scaling Explorer**, and keep the actual-context option enabled to inspect all48 scheduled input endpoints. Choose any of the16 FT0 channels; native values, exact fitted scaled values and recipe parameters remain separate from USD prices.

The event above comes from immutable saved development artifacts. The chart reader does not turn its future label into an input. Forecast cutoff11:30, proxy future close15:30 and nominal exit15:33 are hindsight context, not observed fills. It does **not** first divide the return by historical volatility; that distinct operation belongs to some FT0 inputs. **Show exact canonical numerator and denominator** uses the actual bound return/MAD/epsilon calculation; no denominator is inferred from features.

Restore legitimately provisioned, matching artifacts rather than bypassing verification. Confirmation dates from July2024 are rejected.
