# P2.3A scheduled grid and M2 API

Synthetic engineering foundation only. No production data, 16-channel FT0 calculator, floor/scaler fitting, market join, entry/fill engine or model. Every result retains `research_ready=False`; documented source clocks and floors are caller assertions requiring separate evidence. Existing minute and R1 APIs remain unchanged.

Implementation: `src/lstm_data/m2.py`; focused checks: `python -m pytest tests/test_m2.py tests/test_hourly_proxy.py -q`. Follow README setup.

| Interface | Contract |
|---|---|
| `ScheduledCalendar(start,end)` | Reuses XNYS schedule and session grid; retains complete hours and terminal stub separately. Bounded metadata index shared across requests; no source loading. |
| `scheduled_window(calendar,session,origin)` | Exactly 48 consecutive scheduled completed-hour slots ending at origin 1/2 cutoff. Missing observations cannot shift the index. Insufficient calendar history and structurally invalid early-close origins fail closed. |
| `window_quality(calendar,steps,rows,*,test_scenario=False)` | Five × 48 source CLOSE/time-quality mask, IDs and reasons. Exact intervals, unique observation IDs/keys, availability by each step end. No price fill, skipping or future outcomes argument. `raw_window_eligible` is this limited mask; `full_ft0_eligible=False` always, since OHLCV/features are not audited here. |
| `historical_return(plan,symbol,rows,actions,*,test_scenario=False)` | One stock-specific raw-price log return from accepted exact R1 close references and split transformation over (entry CLOSE,exit CLOSE]. Maturity ≥ scheduled exit and both supported source availability times. Scope covers cutoff through scheduled exit. No TG0 field, peer-label validity, dividend cash or future five-name eligibility. Source/action/version/price/clock facts hash-bound; raw basis denotes the explicit entry share epoch. |
| `ReturnIndex(records)` | Unique stock/session/origin records, reject duplicate keys or minute/mismatched execution/M2 versions; lookup independent of input order. Use factory-produced records. Direct record construction is asserted metadata, not source authentication. |
| `M2FloorCertificate` | Explicit already-derived positive training-volatility fifth-percentile floor assertion, evidence, unique fitting keys and permitted training-prefix bounds. No numerical percentile/population fit or empirical certificate created here. Reject validation/confirmation/warm-up keys, bad clocks or nonpositive floor. Certificate fitted after a requested step is unavailable at that step; this narrow as-of API does not define a later batch preprocessing fit/application policy. |
| `evaluate_m2(calendar,index,symbol,step,origin,floor=None,*,test_scenario=False)` | Last 60 scheduled strictly earlier structurally eligible sessions of the same origin type; numerator uses last 20. No source-missing session removal. Every contribution matured by step's own end. Mean/RMS use available valid returns with ≥19/20, ≥57/60 and max two consecutive missing. Denominator `max(RMS60,certified_floor)`; no TG0 epsilon or silent constant. Missing certificate returns `FLOOR_UNVERIFIED`. Results preserve selected sessions, valid counts, per-session reasons and contributing lineage IDs. |
| `canonical_m2_keys(results)` | Deduplicate identical repeated window appearances by (stock,session,forecast_origin_type); reject conflicting value/provenance for same session-locked key. Return unique key weights, summing 0.5 per origin type for a future single pooled scaler. Both origin types required. No scaler fit. |

New return/feature version `M2:HOURLY_CLOSE_PROXY:v1` binds `COMPLETED_HOURLY_CLOSE_PROXY:v1`. Earlier R1 artifacts retain their historical `REBUILD_REQUIRED` tag; nothing upgrades/relabels old TG0 floors, labels or minute-derived M2 automatically. Rebuild from accepted references through this module. No protocol-pointer migration.

SYNTHETIC fixtures require opt-in. Unknown/ASSUMED source clocks are inactive; `SOURCE_CLOCK_BLOCKED` appears in return/window diagnostics. Production M2 remains blocked until historical publication/action evidence and a reviewed training-floor certificate/population exist. Source retrieval time and bar timestamp cannot substitute for historical availability. ActionScope's complete interval is an evidence assertion inherited from R1, not an independently as-of-verified action feed.

The eligible-session queue is session-locked by calendar, while contributions must pass each historical step's information cutoff. If delayed publication changes otherwise valid M2 values/provenance within the same session/origin, key collection fails `CONFLICTING_SESSION_LOCKED_M2`; no session freeze time or backward copying is invented. A separately reviewed handling rule/evidence is required if this occurs in real data. Training-derived floor/scaler application to earlier batch training steps is also outside this narrow as-of interface.

USA500 and shared execution-proxy approval remain pending/HOLD. Full G2/G3 adequacy, all 48×16×5 feature validity and complete-window retention are not certified by this module.
